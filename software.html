Software

Open-source tools for power system restoration and for AC-feasible operation. They are built to be used: each has a graphical interface, a full user manual, and an automated test suite. Current work is released under the GriRes organization on GitHub.

GriRes Suite

The Grid Resilience Suite is a set of MATLAB toolboxes released under GPL-3.0. The tools share one interface style, one data format (MATPOWER cases) and one documentation standard: every algorithm is stated in full, and every result is checked against an independent computation.

GRIM: Generic Restoration Intelligent Milestone

Restoration planning for grids with AI data centers. Version 4.0.0, November 2026. Release · Manual (96 pages)

After a blackout, a large AI data center keeps running on its backup generation, and its fuel is limited. GRIM puts the data center into the restoration plan, next to generator start-up and the pickup of the other critical loads. It is the successor to HITS and to the milestone method behind the System Restoration Navigator.

  • Tracks the backup fuel of every data center and reconnects the one closest to running out first.
  • Moves the load to the grid in steps. Every step is checked with an AC optimal power flow and, on request, against a frequency limit set by the online inertia.
  • Builds a restoration plan from a complete or a partial outage, or audits a plan proposed by a dispatcher.
  • Logs the Thevenin equivalent at each data center bus for PSCAD and other EMT studies.

GRIT: Grid Realizability Inspection Tool

Is your DC dispatch realizable in the AC grid? Version 1.0.0, November 2026. Release · Manual (45 pages)

Markets and operators dispatch with the DC model, which has no voltages, no reactive power and no losses. GRIT takes a DC dispatch and reports whether the AC grid can carry it, where it fails, and which nearby dispatch works.

  • A full AC check of a 10,000-bus system takes under one second. For systems of 1,354 buses and more, a check costs 7 to 17 percent of one AC-OPF.
  • One run checks bus voltages, branch loadings in MVA, and generator reactive and active limits.
  • Repairs a violated dispatch with the smallest change of generation and voltage set points. Every step is verified by a new AC solution.
  • Checks all single branch outages or the load levels of a whole day in one call.

In preparation: GRIP (admission of periodic AI training loads), GL-ACUC (AC-feasible unit commitment) and GL-VB (virtual bidding with CVaR).

HITS — Healing Touch for Power Systems

The earlier MATLAB toolbox for restoration planning, distributed under the 3-clause BSD license. Kept here for reproducibility; new work should use GRIM.

  • HITS 2.0 (2022): GUI results, vulnerable line set detection, influence graph matrix.
  • HITS 1.0 (2019): command-window restoration planner.

If you use HITS, please cite: Y. Hou, C.-C. Liu, K. Sun, P. Zhang, S. Liu, and D. Mizumura, "Computation of milestones for decision support during system restoration," IEEE Transactions on Power Systems, vol. 26, no. 3, pp. 1399–1409, 2011.

System Restoration Navigator

Developed for the Electric Power Research Institute between 2010 and 2016 (versions 1.0, 2.0, 4.0, 5.0). It evaluates a restoration procedure and builds one interactively with the planner. EPRI gave it a Technology Transfer Award in 2014. It is EPRI's product; contact them for access.
