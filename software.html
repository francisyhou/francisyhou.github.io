Software

Tools for restoration planning and AC-feasible operation. Current work is open source under the GriRes organization on GitHub.

GriRes Suite

MATLAB toolboxes released under GPL-3.0. Each has a user manual and a regression test suite.

GRIM — Generic Restoration Intelligent Milestone

Builds a restoration plan from a complete or partial outage. Models unit cranking, line energization, load pickup, and frequency/RoCoF constraints. It is the successor to HITS and to the milestone method behind the System Restoration Navigator.

DC2AC — DC-to-AC feasibility analyzer

Takes a DC-optimal-power-flow dispatch and reports whether an AC-feasible operating point exists near it, and how far away it is.

In preparation: GL-ACUC (AC-feasible unit commitment) and GL-VB (virtual bidding with CVaR).

HITS — Healing Touch for Power Systems

The earlier MATLAB toolbox for restoration planning, distributed under the 3-clause BSD license. Kept here for reproducibility; new work should use GRIM.

  • HITS 2.0 (2022): GUI results, vulnerable line set detection, influence graph matrix.
  • HITS 1.0 (2019): command-window restoration planner.

If you use HITS, please cite: Y. Hou, C.-C. Liu, K. Sun, P. Zhang, S. Liu, and D. Mizumura, "Computation of milestones for decision support during system restoration," IEEE Transactions on Power Systems, vol. 26, no. 3, pp. 1399–1409, 2011.

System Restoration Navigator

Developed for the Electric Power Research Institute between 2010 and 2016 (versions 1.0, 2.0, 4.0, 5.0). It evaluates a restoration procedure and builds one interactively with the planner. EPRI gave it a Technology Transfer Award in 2014. It is EPRI's product; contact them for access.
